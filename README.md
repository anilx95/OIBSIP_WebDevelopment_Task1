Landing Page – OIBSIP Web Development Task
🚀 Project Overview

This project is a Landing Page built as part of the OIBSIP Web Development Internship Task.
The goal of the project is to design a clean, responsive, and visually appealing landing page using only HTML and CSS.

📌 Objective

Create a modern UI-based landing page.

Use basic front-end technologies (HTML + CSS).

Implement a clean design with proper layout, colors, and typography.

Ensure the webpage is responsive for different screen sizes.

🛠 Technologies Used

HTML5

CSS3

Flexbox / Responsive Design

Modern UI design practices

📂 Project Structure
project/
│── index.html      # Main webpage
│── style.css       # Stylesheet for the landing page

📝 Features Implemented

✔ Modern hero section
✔ Clean typography and layout
✔ Minimal UI with smooth spacing
✔ Fully responsive design
✔ Organized CSS structure

▶ How to Run the Project

Download or clone the repository.

Open the folder.

Double-click index.html — it will open in your browser automatically.

Make sure style.css remains in the same folder as index.html.
